cPanelSniper is a focused exploitation framework for **CVE-2026-41940**, a critical (CVSS 10.0) authentication bypass affecting cPanel & WHM. The vulnerability allows unauthenticated attackers to gain root-level WHM access by injecting CRLF sequences into the session file via the `Authorization` HTTP header — with zero valid credentials required. cPanelSniper automates the entire exploit chain and includes an interactive post-exploitation shell, bulk scanning, and pipeline support — all using pure Python 3.8+ stdlib.

## What cPanelSniper does

cPanelSniper executes a precise 4-stage exploit chain against cPanel & WHM targets to confirm and exploit CVE-2026-41940:

<Steps>
  <Step title="Canonical hostname discovery">
    Automatically discovers the real server hostname via a cpsrvd 307 redirect — preventing Host header mismatches that would break the exploit.
  </Step>
  <Step title="Mint a preauth session">
    Issues a POST to `/login/?login_only=1` with intentionally wrong credentials to obtain a `whostmgrsession` cookie without authentication.
  </Step>
  <Step title="CRLF injection">
    Sends a crafted `Authorization: Basic` header containing CRLF-separated session fields. cPanel's `saveSession()` writes these verbatim into the on-disk session file before sanitization runs.
  </Step>
  <Step title="Propagate and verify">
    Triggers the `do_token_denied` gadget to flush the raw session into the cache, then verifies WHM root access via `/json-api/version`.
  </Step>
</Steps>
